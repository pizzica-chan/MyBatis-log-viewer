        正規表現（大文字小文字無視）に対応しているのは
        Mapper・SQL・パラメータ・スレッド・全文検索 (grep)・ログファイル
        の各フィールドのみです。
        SQL 種別・状態・elapsed・件数・期間は正規表現ではなく、それぞれ列挙・数値・日時として扱われます。
